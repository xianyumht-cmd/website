# NAV 资源数据维护说明

## 唯一数据源

NAV 页面所有资源分区、标题、说明、头像、链接和中英文数据统一维护在：

```text
src/assets/data/nav-catalog.js
```

`src/pages/nav/data.js` 只负责加载这份目录并交给 `initializeResourceData()`；不要再为天卡、周卡、三角洲、HE 等单独新增运行时 patch 文件。

## 修改资源

在 `nav-catalog.js` 中找到对应分区即可新增、修改或删除项目。项目使用 `i(...)`，分区使用 `s(...)`：

```js
i('名称', '说明', 'https://example.com', '图标')
```

需要只展示、不允许点击的项目可使用：

```js
i('名称', '说明', '', '图标', { displayOnly: true })
```

## 中英文数据

中文和英文都放在同一个 `nav-catalog.js` 中维护。已有的语言差异可以保留；如果某次资源调整要求两个语言都同步，则应在同一次修改中更新对应项，避免再通过运行时 patch 临时覆盖。

## 不属于此文件的数据

LOL 当前版本、更新时间和下次更新时间仍只由：

```text
src/assets/data/lol-version.json
```

维护。不要把版本号重新写入 NAV 目录数据。

## 修改后检查

至少确认：

- 页面能正常加载，侧栏分类和资源卡片都能显示；
- 中文/英文切换后各自目录稳定，不会因切换顺序出现不同结果；
- 新增链接正确，已删除资源不会重新出现；
- 搜索功能仍能找到新增资源；
- 桌面端和移动端布局没有异常；
- 不存在新的 `*-patch.js` 资源列表覆盖层。
