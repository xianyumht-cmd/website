# NAV Catalog Verification

Before merging the single-source NAV catalog change:

1. Run `npm run build`.
2. Run `npm run test:unit`.
3. Preview `/down/nav/` on desktop and mobile.
4. Switch between Chinese and English and confirm the same sections/resources remain available.
5. Confirm the daily-card section contains Space, MD, LSC, KDA, acme, 如意/Ruyi, yun, DC, FE, SPOT, and SF.
6. Confirm FY, HP, 骑士/Knight, and 蓝鲸/Blue Whale no longer appear in the daily-card section.
7. Check MD, LSC, KDA, and SF links open the requested destinations.
